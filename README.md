# ZAVOD — «Немой лифт»

Интерактивный вертикальный срез веб-игры по GDD v1.3. Приложение включает создание персонажа, брифинг, схему этажа, наряды, непрерывную работу, дневник, происшествие с необратимым выбором, навыки, новости и летопись.

Опубликованная версия: <https://ratwe.github.io/megazavod/>

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

Игровое состояние хранится в `localStorage`. Команда «Начать заново» доступна в меню справа вверху.

## Telegram Mini App

Приложение автоматически определяет запуск внутри Telegram, разворачивает WebView, учитывает safe area, подключает системную кнопку «Назад», предупреждение при закрытии активной смены и тактильный отклик. В обычном браузере Telegram API не требуется; приложение работает как адаптивный PWA.

Для подключения к боту в `@BotFather`:

1. Выполнить `/newapp` или `/setmenubutton` для нужного бота.
2. Указать URL `https://ratwe.github.io/megazavod/`.
3. Открыть приложение кнопкой меню бота на iOS, Android и Telegram Desktop.

Токен бота клиентскому приложению не нужен и не должен добавляться в репозиторий.
