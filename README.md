# ZAVOD — «Немой лифт»

Интерактивный вертикальный срез веб-игры по GDD v1.3. Приложение включает создание персонажа, брифинг, схему этажа, наряды, непрерывную работу, дневник, происшествие с необратимым выбором, навыки, новости и летопись.

Опубликованная версия: <https://ratwe.github.io/megazavod/>

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

Игровое состояние хранится в `localStorage`. Команда «Начать заново» доступна в меню справа вверху.
